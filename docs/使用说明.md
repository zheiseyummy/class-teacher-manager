# 班主任综合管理系统使用说明

## 1. 软件说明

本软件在 Windows 本地运行，不需要联网。学生信息、综合素质评价、成绩、课程、日程和备份设置均存入本机 SQLite 数据库。软件启动后默认进入“今日班级工作台”，左侧可切换学生数据、评价、成绩、德育、考勤、课程日历和数据备份模块。

侧栏和各模块的主分栏可以用鼠标拖动调整宽度；成绩详情中的两张分析表可上下调整；所有主要表格列均可拖动调宽和移动顺序。调整后的分栏尺寸会自动记住。

## 2. 启动与数据安全

1. 双击项目根目录的 `启动班主任管理系统.bat`。
2. 第一次在新电脑使用时，请先按 README 中的命令安装 Python 依赖。
3. 源码运行的数据文件位于 `data/class_manager.db`，默认备份目录为 `backups/`。打包版的数据和备份均位于 `%LOCALAPPDATA%\LocalClassManager\`。
4. 请不要在软件运行时手动复制、替换或删除数据库文件；请使用“数据备份与恢复”模块创建 ZIP 备份或执行恢复。

### 教师信息、个人标记与版本号

首次启动时，软件会提示填写教师信息。教师姓名为保存时的必填项；学校名称、任教学科、常用班级、默认学期和个人标记均可稍后补充。

- 点击首页顶部的问候语，可以打开教师信息设置。
- 点击左侧菜单最底部的个人标记，也可以再次修改。
- 未填写自定义标记时，系统自动显示“姓名老师 · 个人教学工作台”。
- 修改并保存后，首页问候与侧栏标记会立即刷新，不需要重启。
- 选择“稍后设置”不会阻止软件使用，也不会在每次启动时重复弹出。
- 教师资料只保存在当前本地数据库中，不包含账号、密码、身份证号或联系电话。

左侧底部同时显示当前程序版本。当前正式版本为 `v1.0.1`；新创建的 ZIP 备份清单也会记录该版本号。

## 3. 学生数据中心

### 新建与维护

1. 先点击顶部“管理班级”建立班级。
2. 点击“新增学生”填写姓名、性别、学号、年级、座号等资料。
3. 在学生表格中点击一名学生，可在右侧查看档案和多个家长联系人；点击“编辑”修改资料。

顶部搜索支持姓名、学号和家长电话，班级下拉框可筛选学生。

### 学生 Excel 导入

点击顶部“导入 Excel”菜单中的“打开导入模板”，使用 `学生信息导入模板.xlsx` 填写资料。导入时：

- 必填列：`姓名`、`班级`。
- 可选列：性别、学号、年级、座号、出生日期、身份证号、民族、学生备注，以及家长资料。
- 同班同学号或相同身份证号的学生会被识别为重复并跳过。
- 导入结果窗口会列出成功、跳过、失败和具体原因。

### 学生 Excel 导出

顶部“导出 Excel”菜单可导出全部学生、当前班级学生，或家长通讯录。

## 4. 综合素质评价

综合素质评价共有五个固定维度：思想品德、学业水平、身心健康、艺术素养、实践与创新。每个学生有六个学期：初一上、初一下、初二上、初二下、初三上、初三下。

### 手动录入

1. 在左侧学生列表选择学生。
2. 在右侧选择学期。
3. 为五个维度选择 A、B、C 或 N/A，点击“保存本学期评价”。
4. 右下方会显示学期得分、五维得分和总分。

`N/A` 适用于转入学生缺失学期或不适用的评价，不产生分数，但会保留在记录和导出表中。累计分只汇总已有学期，不会按满分折算或补齐。

### 综合素质 Excel 导入

点击“导入 Excel”，选择含六个学期表的文件。工作表可命名为：

| 学期 | 可识别名称 |
| --- | --- |
| 初一上 | 七上、七年级上、初一上、初一上学期 |
| 初一下 | 七下、七年级下、初一下、初一下学期 |
| 初二上 | 八上、八年级上、初二上、初二上学期 |
| 初二下 | 八下、八年级下、初二下、初二下学期 |
| 初三上 | 九上、九年级上、初三上、初三上学期 |
| 初三下 | 九下、九年级下、初三下、初三下学期 |

每张表需要：`姓名`、思想品德、学业水平、身心健康、艺术素养、实践与创新。`实践创新`也可识别；`学号`为可选列并优先用于匹配，可以保留序号列；“总计”等额外工作表会自动忽略。

- 不选择班级时，系统会使用“综合素质导入班”，并自动建立 Excel 中的学生档案。
- 选择班级后，数据会导入该班；Excel 中的新学生也会自动建档。
- 某学生缺少某个学期或维度时，系统会写入 `N/A`。
- 每张工作表的实际名单会单独记录，最终评定只采用九下工作表中的学生；九下前已经转出的学生仍保留历史评价，但不进入最终排名。

### 最终五维评定

1. 完成九下数据导入后，点击“最终评定”。
2. 选择班级和维度，点击“重新计算”。五个维度分别按六学期累计分进行班级排名，相同累计分使用相同名次和相同系统等级。
3. 系统按班级分配 A/B/C：A 接近 60%，边界同分时最多允许多 1 人；C 取最接近 5% 的末位完整同分组；其余为 B。同分组不会被系统拆开。
4. 六学期不完整的学生会置顶并标黄，缺失项保持 `N/A`，仍按已有累计分正常参加排名和等级分配。
5. 教师可在“最终等级”列调整 A/B/C，但不能修改累计分、排名或原始六学期评价。窗口会实时显示各等级人数、比例和人工调整数量。
6. 核对后点击“锁定结果”。锁定后本班原始评价、Excel 重新导入和最终等级均不可修改；如需更正，先在同一窗口解锁。

点击“导出 Excel”可得到“综合素质总表”“五维得分”“学期得分”“最终评定”四个工作表。最终评定表以九下名单为准，包含六学期 30 项原始等级、五维累计分、五维班级排名、系统等级、教师确认等级、五维总分和总排名。

## 5. 成绩管理

### 导入一次考试

1. 打开“成绩管理”，点击“导入成绩”。
2. 填写考试名称、日期、学期和年级，再选择 Excel 文件。
3. Excel 首个工作表应包含 `姓名` 和至少一门学科；`学号`、`班级`为可选列。

支持的学科为：语文、数学、英语、物理、化学、政治、历史、地理、生物。只保留本次实际参加考试的列即可。表头可写成 `语文`，也可写成 `语文(120)` 或 `语文（120）` 标记满分；“道德与法治”“道法”会自动识别为政治。

空白、缺考、未考等单元格不会写入该科成绩。点击“成绩模板”可打开九学科示例模板后自行删除未参加的学科列。

### 匹配与更正

- 有班级列时，系统优先按班级和学号匹配；没有学号时按班级和姓名匹配。
- 未建档学生会自动建立；没有班级列时会进入“成绩导入班”。
- 考试名称、日期、学期、年级完全相同时，再次导入会更新该次考试的已有成绩，适合更正原表。

### 分析功能

- **成绩总览**：总分、班级排名、年级排名及本次已导入学科成绩。分数相同并列。
- **学科分析**：当前范围内各科参考人数、平均分、最高分、最低分。
- **学科趋势**：每科在多次考试中的平均分和相对上次变化；各次考试不要求学科相同。
- **班级趋势**：选择班级后显示班均分、年级均分和班级均分排名。
- **学生分析**：在成绩总览中选择学生，右侧会展示历次总分、班级/年级排名，以及本次各科与班均的差异。低于班均 10% 标记为“偏弱”，高于班均 10% 标记为“优势”。

## 6. 打包为 exe

请先关闭正在运行的软件，再双击 `打包当前版本.bat`。首次打包时会安装 PyInstaller，完成后运行：

```text
dist-python/ClassTeacherManager/ClassTeacherManager.exe
```

打包版的数据不会写入项目目录，而是保存在 `%LOCALAPPDATA%\LocalClassManager\`。升级或替换打包版前，请先关闭软件并备份该目录中的数据库文件。

## 7. 后续扩展

当前备份模块支持本地 ZIP 备份、恢复和软件运行期间的定时任务。密码加密备份、网络同步和 Windows 任务计划程序级别的关机后自动备份，可根据后续使用习惯继续增加。

## 8. 请假与考勤

“请假与考勤”模块用于统一登记病假、事假、迟到、早退、缺勤和其他特殊情况。每条记录均关联已有学生档案，并保存开始时间、结束时间、处理状态、事由和备注。

1. 点击右上角“新增记录”，选择班级与学生，再填写记录类型、时间和事由后保存。
2. 点击左侧表格中的记录，可在右侧查看完整详情；使用“编辑”可更正内容，使用“删除”会将该记录移出当前列表。
3. 顶部可按学生姓名、学号、事由、班级和记录类型筛选；勾选“日期范围”后，还可限定统计和列表所使用的日期区间。
4. 页面会实时显示当前筛选范围内的记录总数、请假条数、迟到次数、早退次数和缺勤次数。
5. 点击“导出 Excel”会导出当前筛选结果，适合留存或提交班级考勤汇总。

## 9. 德育评价

“德育评价”模块用于记录学生参加集体活动、获得奖项、志愿服务、班级服务和社会实践等正向表现。系统不会自动设定积分规则，德育积分由班主任按本班实际情况手动填写。

1. 点击右上角“新增记录”，选择学生、类别和日期，填写活动或奖项名称；获奖记录可额外选择校级、区县级、市级、省级或国家级等奖项级别。
2. 可补充主办方、德育积分和备注，例如证书信息、学生承担的职责或表现说明。
3. 点击列表中的记录后，右侧会展示该生累计记录数、集体活动次数、获奖项目数和累计德育积分，并支持编辑或删除当前记录。
4. 顶部支持按学生、学号、活动或奖项、班级、类别和日期范围筛选；页面统计会随筛选范围实时变化。
5. 点击“导出 Excel”可导出当前筛选范围内的德育评价记录。

## 10. 今日班级工作台

软件启动后会优先显示“今日班级工作台”。在右上方选择班级后，页面会汇总显示；旁边的日期始终显示系统当天日期，只用于查看，不能点击或手工修改：

- 当天课程和当天班级、全局日程；课程来自已关联到该学生班级且日期覆盖当天的教学班；
- 在班学生数、当天课程数、当天考勤记录数和当天德育记录数；
- 最近两次同学期考试中波动较大的学生，包含两次总分、班级排名变化和变化最大的两个共同学科；
- “查看课表”“新建日程”“考勤”“德育”“成绩分析”等快捷入口。

两次考试科目不完全相同时，总分旁会显示“科目不同”，用于提醒总分差不能直接代表真实进退步；共同学科仍会正常比较。“新建日程”会直接打开日程录入窗口，其余快捷入口会跳转到对应模块。工作台的左右、上下分栏均可拖动调整，表格列也可自行调整宽度。

## 11. 课程表与日历

### 课程表

1. 进入“课程表与日历”的“课程表”页后，先点击“学期与课时”，新建一个学期并设置开始、结束日期。系统会阻止日期重叠的学期，避免同一天混用两套课程表。
2. 在同一个窗口内按需要新增课时。每天可以是任意数量的课时，每个课时可设置显示顺序、名称和起止时间，例如早读、午休、晚自习都可以单独建立。
3. 点击“管理教学班”新建教学班并选择颜色。教学班可完全独立使用，无须先建立学生班级；也可以选择关联“学生数据中心”已有班级，以便在今日班级工作台自动显示当天课程。
4. 回到课程表，在顶部选择学期和教学班。双击空白课程格可新增课程，双击已有课程格可编辑；课程可填写名称、教师、地点和备注。
5. 选择“全部教学班”可在同一张表中汇总查看多个教学班，并按教学班颜色区分。汇总状态只用于查看，切换到具体教学班后才能编辑，避免误改其他班级课程。
6. 同一教学班、同一学期、同一星期、同一课时只能保留一节课程；不同教学班和不同学期可使用相同时间段，彼此独立。

课程表显示周一至周日，网格行数与时间完全来自当前学期的课时设置。若旧版本已有按学生班级录入的课程，首次升级会迁移到“旧版课程表（请设置日期）”；修改其日期后即可把它作为实际学期使用。

### 日历

1. 进入“日历”页后，可选择查看全部班级，或只查看一个班级及其全局日程。
2. 在日历中选择日期，再点击“新增日程”。日程可设为某个班级，也可选择“全局日程”。
3. 全局日程会在所有班级视图和工作台中显示，例如年级会议、统一考试安排；班级日程只会显示给对应班级。
4. 有日程的日期会以浅色标记。单班级日程使用该班级颜色，多条日程使用中性浅灰标记。
5. 选中右侧日程表中的一行后，可编辑或删除。双击该行也可直接编辑。

日历页面的左右分栏和右侧表格列均可按个人习惯拖动调整，调整尺寸会在下次启动时保留。

## 12. 数据备份与恢复

### 完整备份

1. 进入“数据备份与恢复”，点击“立即完整备份”或“创建完整数据备份”。
2. 选择保存位置后，系统会生成一个 `.zip` 文件，内部包含备份说明、完整性校验信息和 SQLite 数据快照。
3. 备份历史会显示可用文件、创建时间和用途，可选中一项后打开所在文件夹。

完整备份保存的是当前全部本地数据，包括学生、家长、综合素质、成绩、考勤、德育、课程、日历和备份设置。

### 学期归档

1. 先在“课程表与日历”的“学期与课时”中建立学期日期范围。
2. 在备份中心选择该学期，点击“归档所选学期”。
3. 系统会将学期名称、日期范围及课程、日程、成绩、德育、考勤等统计写入归档说明，并同时保存完整数据库快照。

学期归档适合在期末留档。它可以完整恢复到归档创建时的数据状态，而不是只把某一个学期的数据合并回当前数据库。

### 定时备份

1. 勾选“启用自动备份”，选择每天或每周、执行时间和保存位置。
2. 点击“保存定时备份设置”。
3. 软件保持运行并到达设定时间后，会自动创建完整 ZIP 备份，记录会出现在备份历史中。

自动备份不会在软件关闭后自行启动；若需要电脑开机但软件未运行时也能备份，可在后续版本接入 Windows 任务计划程序。

### 恢复数据

1. 点击“导入 ZIP 恢复”，或在备份历史中选择文件后点击“恢复所选备份”。
2. 系统会先检查 ZIP 结构、文件校验值和 SQLite 完整性。
3. 确认后，系统先创建“恢复前安全备份”，再替换当前全部数据并自动重启软件。

恢复会覆盖当前所有本地数据。请确认选择的是正确的备份文件，并保留自动生成的恢复前安全备份，以便必要时回退。
