# 下一阶段开发确认清单

> 确认日期：2026-08-19
> 状态：需求已确认；第一小步已完成，下一步进入统一学期与学生就读历史
> 适用项目：班主任综合管理系统 Windows 本地版

## 一、产品定位

1. 软件继续采用 Windows 本地桌面方式运行。
2. 每位教师独立安装、独立使用自己的 SQLite 数据库和备份文件。
3. 不增加账号登录、多教师切换和复杂权限系统。
4. 教师可以把软件复制给其他任课教师使用，但各自的数据互不关联。
5. 下一阶段不继续扩张新业务模块，优先完善学期、班级、成绩导入、成绩分析和期末输出流程。

## 二、学年与学期管理

### 2.1 统一学期

1. 建立统一的学年和学期记录。
2. 考试、综合素质评价、请假考勤、课程表和学生就读关系应关联同一学期。
3. 学年建议采用“2026-2027 学年”格式。
4. 学期分为上学期和下学期，并保存开始、结束日期。
5. 软件内只能有一个当前学期，但历史学期可以随时查看。

### 2.2 新学期处理

1. 创建同一学年的下学期时，默认沿用原班级和学生名单，不提升年级。
2. 进入新学年时，所选班级自动升入下一年级。
3. 新学期向导支持同时勾选一个或多个班级。
4. 默认选中全部在读班级，教师可以取消不再任教的班级。
5. 执行前逐班显示名称、年级、人数和人员变化预览。
6. 未被勾选的班级只是不延续到新学期，不删除历史档案。

### 2.3 班级自动命名

1. 标准班名默认按照以下方式自动递进：
   - 初一1班 -> 初二1班
   - 初二1班 -> 初三1班
2. 教师可在升年级确认前逐班修改新班名。
3. 初三班完成最后一个学期后进入“已毕业/已归档”状态，不自动创建高中班级。
4. 非标准班名不强制修改，只在预览页提供建议名称。

## 三、学生就读历史

1. 学生个人档案与“学生在某学期属于哪个班级”分开保存。
2. 学生换班、转入或转出后，旧学期的班级、成绩和综合素质记录保持不变。
3. 当前班级支持以下操作：
   - 新增学生
   - 转入已有学生
   - 从本班移出学生
   - 更换班级
4. “从本班移出”只结束当前就读关系，不删除学生历史档案。
5. 只有误录且没有任何关联数据的学生，才允许永久删除。
6. 名单变化应记录生效学期，备注可选。

## 四、课程表延续

1. 创建新学期时增加“复制上一学期课程表作为草稿”复选框。
2. 该选项默认不勾选。
3. 勾选后复制课程、教学班、节次和上课时间。
4. 复制后的课程表归属于新学期，可单独修改。
5. 旧学期课程表保持为历史记录，不与新学期混合。
6. 教师确认新课表后，再将其设为当前使用课表。

## 五、学期更新备份

1. 每次创建新学期或执行整班升年级前，系统必须自动创建本地 ZIP 恢复点。
2. 自动备份不提供关闭开关。
3. 备份名称包含目标学期和创建时间，例如：

   `学期更新前_2026-2027学年上学期_20260819-153000.zip`

4. 创建备份失败时，不执行学期更新。
5. 更新过程中发生错误时，数据库操作整体回退，避免出现只更新一部分班级的情况。
6. 自动恢复点可以在现有“数据备份与恢复”模块中查看和恢复。

## 六、成绩 Excel 导入流程

### 6.1 导入步骤

1. 选择 Excel 文件。
2. 识别工作表、表头、学号、姓名、科目和排名字段。
3. 填写或确认考试名称、日期、学期和考试类型。
4. 确认本次考试包含的科目及各科满分。
5. 预览学生匹配与异常检查结果。
6. 教师确认后才正式写入数据库。

### 6.2 预览与异常检查

预览阶段不修改数据库，并显示：

- 已匹配学生
- 未匹配学生
- 重复学号
- 重复考试记录
- 缺考或空值
- 超过科目满分的成绩
- 本次未参加考试的科目
- 无法识别的列

### 6.3 导入批次

1. 每次正式导入保存为一个独立批次。
2. 保存来源文件、导入时间、考试、学期、成功数量和错误清单。
3. 考试锁定前，可以一键撤销整个导入批次。
4. 考试锁定后不可直接撤销；需要先执行带提示的解锁或修订流程。
5. 支持保存月考、期中、期末和教育局成绩表的字段映射方案。
6. 后续补充 `.xls` 和 `.xlsx` 两种格式支持。

## 七、成绩比较规则

1. 进退步主要依据班级排名和年级排名变化。
2. 进步、退步阈值由教师输入，例如 10 名或 20 名。
3. 单科成绩在满分变化时使用得分率辅助比较。
4. 单科偏科分析同时参考该科在班级或年级中的相对位置。
5. 只有考试科目范围一致时，才直接比较总分变化。
6. 科目范围不一致时，界面明确提示“总分不可直接比较”。
7. 未参加的考试或科目显示 N/A，不按 0 分计算。
8. 默认在同一学期内进行多次考试比较。
9. 后续自动生成以下名单：
   - 明显进步
   - 明显退步
   - 持续波动
   - 偏科关注

## 八、教师信息与个人标记

### 8.1 教师信息

增加轻量的本地教师信息设置，不单独占用左侧菜单。建议包含：

- 教师姓名（必填）
- 学校名称（选填）
- 任教学科（可多选并支持自定义）
- 常用班级（从已有教学班中多选）
- 默认学年和学期
- 自定义个人标记（选填）

首次使用时提示填写，允许暂时跳过；之后可通过顶部问候语或底部个人标记再次打开设置。

### 8.2 界面联动

1. 首页问候根据教师姓名显示，例如“您好，李老师！”。
2. 左侧菜单最底部显示版本号和个人标记。
3. 未填写自定义标记时，自动显示：

   `XXX老师 · 个人教学工作台`

4. 个人标记使用较小、较淡的文字，不抢占主要工作区域。
5. 教师信息修改后，首页问候和底部标记立即刷新。
6. 学校和教师姓名可用于导出报告标题及署名。

## 九、版本规划

1. 当前开发版本统一标记为 `v0.9.0`。
2. 完成成绩分析、期末输出和完整数据流程验收后，发布 `v1.0.0`。
3. 版本号只在一个统一位置维护。
4. 以下位置读取同一个版本号：
   - 左侧菜单底部
   - ZIP 备份清单
   - Excel/PDF 导出报告
   - 后续 EXE 文件信息
5. 每完成一个任务不立即打包 EXE；只有教师明确提出时才执行打包。
