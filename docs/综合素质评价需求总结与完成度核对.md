# 综合素质评价需求总结与完成度核对

> 核对日期：2026-07-23
> 核对范围：本轮关于六学期综合素质原始评价、五维累计排名、最终 A/B/C 分档、教师复核锁定及 Excel 导出的需求。

## 一、最终确认的业务目标

建立一个可独立使用的综合素质评价模块，按班级保存学生六个学期、五个维度的原始 A/B/C 评价。完成九年级下学期评价后，以九下名单为最终名单，计算五个维度各自的累计得分和班级排名，再按约定比例自动分配最终 A/B/C 等级。教师核对后可以只调整最终等级，确认无误后锁定并导出完整档案。

### 五个评价维度

1. 思想品德
2. 学业水平
3. 身心健康
4. 艺术素养
5. 实践与创新

### 六个学期

1. 七年级上学期
2. 七年级下学期
3. 八年级上学期
4. 八年级下学期
5. 九年级上学期
6. 九年级下学期

## 二、原始等级赋分规则

下表是单个维度在各学期的换算分。完整六学期时，单个维度满分 10 分，五个维度总分 50 分。

| 学期 | A | B | C |
| --- | ---: | ---: | ---: |
| 七上 | 0.80 | 0.72 | 0.64 |
| 七下 | 1.20 | 1.08 | 0.96 |
| 八上 | 1.20 | 1.08 | 0.96 |
| 八下 | 1.80 | 1.62 | 1.44 |
| 九上 | 2.00 | 1.80 | 1.60 |
| 九下 | 3.00 | 2.70 | 2.40 |

当前录入界面只提供 `A`、`B`、`C`、`N/A`。最终等级只允许 `A`、`B`、`C`，不出现 D。程序底层仍保留旧版 D 数据的读取兼容，目的是避免升级后丢失历史记录；新录入界面不会再提供 D。

## 三、最终确认的数据规则

### 1. Excel 原始底册

- 每个班级一份 Excel 文件。
- 文件包含六张学期工作表，可识别：`七上`、`七下`、`八上`、`八下`、`九上`、`九下`及其完整名称。
- 每张表包含姓名和五个维度；学号为可选列并优先用于学生匹配。
- `实践与创新`和`实践创新`均可识别。
- 额外的“总计”“赋分统计”等工作表不会作为学期数据导入。
- 未提前建立学生档案时，可以在综合素质模块中直接导入，系统自动创建目标班级和学生。

### 2. 九下最终名单

- 最终排名和最终等级只采用九下工作表中实际出现的学生。
- 九下前已经转出的学生继续保留历史评价，但不进入最终排名和最终评定导出名单。
- 九下出现但早期学期缺失的转入学生，仍进入最终排名和等级分配。

### 3. 缺失学期

- 缺少的学期或维度显示为 `N/A`。
- 已存在的原始等级正常保留。
- `N/A` 不产生分数，也不按满分进行比例补齐或标准化。
- 学生累计分等于已有学期换算分之和，数据不完整的学生仍参加排名和分档。
- 教师复核界面将数据不完整的学生置顶并用黄色突出显示。

### 4. 五维排名

- 五个维度分别计算六学期累计分。
- 五个维度分别在本班内排名，不跨班混排。
- 相同累计分使用相同名次，排名方式为竞赛排名，例如 `1、2、2、4`。
- 自动分档时，相同累计分的学生必须处于同一等级，不能拆开同分组。
- 另行计算五维总分和五维总分班级排名。

### 5. 最终 A/B/C 分配

- A 的目标比例为 60%。
- A 可以因人数取整或边界同分最多多 1 人，不能再多。
- 如果加入 A/B 边界的整个同分组会使 A 超过允许上限 2 人或更多，则整个同分组进入 B。
- C 的目标比例为 5%，从末位开始按完整同分组确定最接近目标的人数。
- 当两种 C 人数与目标距离相同时，选择人数较少的方案。
- 其余学生为 B，因此 B、C 会根据同分边界适当浮动。

已覆盖的末位示例：

| 情况 | 处理结果 |
| --- | --- |
| 最后三人分数均不同 | 最后两人为 C |
| 倒数第 2、3 人同分，最后 1 人更低 | 同分的两人为 B，最后 1 人为 C |
| 最后两人同分 | 最后两人均为 C |

### 6. 教师复核与锁定

- 系统先生成累计分、班级排名、系统等级和最终等级。
- 教师只能把最终等级调整为 A、B 或 C。
- 教师不能在最终复核窗口修改六学期原始等级、累计分或排名。
- 窗口实时显示 A/B/C 人数、比例、人工调整数量和数据不完整人数。
- 锁定前检查每个维度的 A 人数是否超过允许上限。
- 锁定后，本班原始评价、Excel 重新导入和最终等级均不能修改。
- 如需更正，可先解锁，再重新计算或调整。

### 7. 最终 Excel 档案

导出文件包含四张工作表：

1. `综合素质总表`
2. `五维得分`
3. `学期得分`
4. `最终评定`

其中“最终评定”以九下名单为准，包含：

- 学生姓名、学号、班级；
- 六学期乘五维度，共 30 项原始评价；
- 五个维度各自的累计得分；
- 五个维度各自的班级排名；
- 五个维度各自的系统等级；
- 五个维度各自的教师确认等级；
- 五维总分和五维总分班级排名；
- 数据完整状态和复核锁定状态。

## 五、明确取消或不再纳入本轮的内容

根据后续确认，以下早期设想不再作为本轮需求：

- 不建立综合素质扣分项目明细。
- 不根据违纪记录自动扣减思想品德。
- 不根据成绩模块自动生成每学期学业水平等级。
- 不自动计算体育、艺术或社会实践的过程积分。
- 软件只记录教育部门提供的学期 A/B/C 原始评价，并在六学期结束后负责累计、排名和最终分档。
- 不加入家访、家长谈话等记录。
- 不增加当地户籍、连续就读、均衡生资格或不符合原因字段。
- 不按照均衡生资格筛选或排除学生，九下名单中的学生统一参加最终排名和分档。
